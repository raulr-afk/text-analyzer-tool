# Text Analyzer Tool

A beginner-friendly Python script designed to parse text strings and extract basic linguistic metrics. This tool demonstrates core Python competencies including string manipulation, functions, and basic text processing.

## Features
* **Word Count:** Splits and counts total words in a text block.
* **Character Count:** Measures total string length including spaces.
* **Sentence Detection:** Counts sentences based on punctuation markers (`.`, `!`, `?`).
* **Average Word Length:** Computes the average character length per word.

## How to Run
Simply execute the script using Python 3:
```bash
python analyzer.py
```
